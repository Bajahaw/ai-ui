# Example Skills

This folder contains example skills for AI UI.

Skills are reusable instruction prompts that the AI can read during a conversation. Upload them via **Settings → Skills** in the app.

To create your own skill, write the instructions in a Markdown (`.md`) file and upload it through the UI.

| File | Name to upload | Purpose |
|------|----------------|---------|
| `good-widgets.md` | `good-widgets` | Native full-width chat widget layout/theming |
| `match-stats-widget.md` | `match-stats-widget` | Football match widgets via TheSportsDB (API, search, design) |
